{% blocktrans trimmed %}Quadrum is a Django-based Simple Management System for product inventory, point-of-sale (POS) sales, accounts receivable, and basic reporting. This page covers the basics of signing in, finding your way around, and the everyday workflows.{% endblocktrans %}

{% blocktrans trimmed %}Accounts and access{% endblocktrans %}

    {% url 'frontend:register' as _u1 %}
  • {% blocktrans trimmed %}You can create your own account from the registration page. Every operational area requires signing in.{% endblocktrans %}
  • {% blocktrans trimmed %}Any successfully registered account can access the operational pages: Dashboard, Sales, Products, Inventory, People, Finance, and Reports. There are no additional roles inside the application.{% endblocktrans %}
  • {% blocktrans trimmed %}Registration never grants Django staff or superuser privileges. Application access and administrative privileges are separate.{% endblocktrans %}
  • {% blocktrans trimmed %}When your session ends, sign in again to continue. Saved data is not affected.{% endblocktrans %}

{% blocktrans trimmed %}First-run guide{% endblocktrans %}

  • {% blocktrans trimmed %}Newly registered accounts see the getting started guide once. You can skip it or finish it; either way it will not appear again on its own while a guide is pending.{% endblocktrans %}
  • {% blocktrans trimmed %}The guide's current step is stored per account, so it resumes where you left off even after navigating or signing back in.{% endblocktrans %}
    • {% url 'frontend:documentation' as _u1 %}
  • {% blocktrans trimmed %}Replay it any time with Show getting started guide on the Documentation index.{% endblocktrans %}

{% blocktrans trimmed %}Getting around{% endblocktrans %}

  • {% blocktrans trimmed %}The sidebar links to every area of the system; collapse it with Ctrl+B on desktop.{% endblocktrans %}
    • {% url 'frontend:documentation_topic' 'search' as _u1 %}
  • {% blocktrans trimmed %}The header search (or Ctrl+K) opens the global search palette — see Search and Advanced Queries.{% endblocktrans %}
    • {% url 'frontend:documentation_topic' 'preferences-troubleshooting' as _u1 %}

{% blocktrans trimmed %}Daily workflows{% endblocktrans %}

    {% url 'frontend:documentation_topic' 'sales-pos' as _u1 %}
  1. {% blocktrans trimmed %}Record a sale. Open New Sale, pick products by category, and adjust quantities. Choose the payment method (Cash, Debit, Credit, PIX, or On Account), then select Finalize Sale. The sale is recorded as Completed and stock is deducted. See Sales and Point of Sale.{% endblocktrans %}
    2. {% url 'frontend:documentation_topic' 'products-inventory' as _u1 %}
  2. {% blocktrans trimmed %}Adjust stock. Open Inventory and use the stock adjustment form. Enter a positive quantity to add stock or a negative quantity to remove it, and include a reason. Every adjustment is stored as a stock movement. See Products and Inventory.{% endblocktrans %}
    3. {% url 'frontend:documentation_topic' 'finance' as _u1 %}
  3. {% blocktrans trimmed %}Register a payment. Open Finance, pick the receivable, and enter the amount and method. A payment cannot exceed the remaining balance; the receivable status updates automatically. See Finance and Receivables.{% endblocktrans %}
    4. {% url 'frontend:dashboard' as _u1 %} {% url 'frontend:reports' as _u2 %}
  4. {% blocktrans trimmed %}Review results. Use the Dashboard for the current picture and Reports for period summaries.{% endblocktrans %}
