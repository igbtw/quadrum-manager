{% blocktrans trimmed %}The Dashboard is the landing page after sign-in. It summarizes the current day and recent activity; the Reports page covers longer periods.{% endblocktrans %}

{% blocktrans trimmed %}Overview cards{% endblocktrans %}

  • {% blocktrans trimmed %}Sales today — the number of Completed sales created today.{% endblocktrans %}
  • {% blocktrans trimmed %}Revenue today — the sum of the totals of those Completed sales, shown in R$ with two decimals.{% endblocktrans %}
  • {% blocktrans trimmed %}Open receivables — the sum of the original amounts of receivables currently in Pending, Partial, or Overdue state (not the remaining balance after payments).{% endblocktrans %}
  • {% blocktrans trimmed %}Low stock — the number of active products whose stock is at or below their minimum stock, but still above zero.{% endblocktrans %}

{% blocktrans trimmed %}Alerts and activity{% endblocktrans %}

  • {% blocktrans trimmed %}Low-stock list — active products with stock at or below the minimum threshold, with their current quantities.{% endblocktrans %}
  • {% blocktrans trimmed %}Out-of-stock count — active products with zero stock; these cannot be sold until restocked.{% endblocktrans %}
    • {% url 'frontend:sales_list' as _u1 %}
  • {% blocktrans trimmed %}Recent sales — the five most recent sales with their code, total, and status. The full history is on the Sales page.{% endblocktrans %}

{% blocktrans trimmed %}Where the numbers come from{% endblocktrans %}

  • {% blocktrans trimmed %}All dashboard figures are computed from the database at page load; there is no caching layer to refresh.{% endblocktrans %}
  • {% blocktrans trimmed %}“Today” uses the server's current date and time zone.{% endblocktrans %}
    • {% url 'frontend:documentation_topic' 'finance' as _u1 %}
  • {% blocktrans trimmed %}Because the open-receivables card uses original amounts, it can exceed the money actually still owed once payments are registered. The remaining balance per receivable is visible on Finance.{% endblocktrans %}

{% blocktrans trimmed %}The detailed aggregation rules are documented for developers in docs/business-flows.md (repository file, not served by the application).{% endblocktrans %}
