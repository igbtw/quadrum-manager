{% blocktrans trimmed %}Global search opens with Ctrl+K (or Cmd+K on macOS) from any page. It has two modes: with an empty field it browses destinations by category tab; once you type at least two characters it searches real data live.{% endblocktrans %}

{% blocktrans trimmed %}Browse mode{% endblocktrans %}

  • {% blocktrans trimmed %}With an empty field, the tabs All, Pages, Docs, Products, People, and Sales show what each category can search and how to query it.{% endblocktrans %}
  • {% blocktrans trimmed %}Switching tabs never clears your query; clearing the query returns to browse mode.{% endblocktrans %}

{% blocktrans trimmed %}Search mode{% endblocktrans %}

  • {% blocktrans trimmed %}Type two or more characters: matching pages and documentation topics appear immediately, and products, people, and sales are fetched from the server as you type.{% endblocktrans %}
  • {% blocktrans trimmed %}Unprefixed searches cover every resource type at once.{% endblocktrans %}
  • {% blocktrans trimmed %}Results always link to a real destination: pages open the page, documentation opens the topic page, products open the Products listing, people open the People listing already filtered by the matched name, and sales open the Sales history.{% endblocktrans %}

{% blocktrans trimmed %}Advanced prefixes{% endblocktrans %}

{% blocktrans trimmed %}Prefix{% endblocktrans %}{% blocktrans trimmed %}Searches{% endblocktrans %}{% blocktrans trimmed %}Example{% endblocktrans %}
page:{% blocktrans trimmed %}Application pages by name or keyword.{% endblocktrans %}page:inventory
doc:{% blocktrans trimmed %}Documentation topics.{% endblocktrans %}doc:receivables
product:{% blocktrans trimmed %}Products by name or code.{% endblocktrans %}product:rice
person:{% blocktrans trimmed %}People by name or registration/record number.{% endblocktrans %}person:maria
sale:{% blocktrans trimmed %}Sales by code or customer name.{% endblocktrans %}sale:1042
  • {% blocktrans trimmed %}Prefixes are case-insensitive and tolerate surrounding whitespace: PRODUCT: rice works like product:rice.{% endblocktrans %}
  • {% blocktrans trimmed %}A recognized prefix with no term yet shows a prompt explaining what can be searched (for example, person: asks for a name or document).{% endblocktrans %}
  • {% blocktrans trimmed %}Unknown prefixes are treated as ordinary search text, not as errors.{% endblocktrans %}
  • {% blocktrans trimmed %}Each resource type returns up to five results, and sensitive fields — like people's email and phone — are never included.{% endblocktrans %}

{% blocktrans trimmed %}Keyboard use{% endblocktrans %}

  • {% blocktrans trimmed %}↑/↓ move through results, Enter opens the highlighted result, and Esc closes the palette.{% endblocktrans %}
  • {% blocktrans trimmed %}Tab and the arrow keys move between category tabs when a tab is focused.{% endblocktrans %}
