Global search opens with Ctrl+K (or Cmd+K on macOS) from any page. It has two modes: with an empty field it browses destinations by category tab; once you type at least two characters it searches real data live.

Browse mode

  • With an empty field, the tabs All, Pages, Docs, Products, People, and Sales show what each category can search and how to query it.
  • Switching tabs never clears your query; clearing the query returns to browse mode.

Search mode

  • Type two or more characters: matching pages and documentation topics appear immediately, and products, people, and sales are fetched from the server as you type.
  • Unprefixed searches cover every resource type at once.
  • Results always link to a real destination: pages open the page, documentation opens the topic page, products open the Products listing, people open the People listing already filtered by the matched name, and sales open the Sales history.

Advanced prefixes

PrefixSearchesExample
page:Application pages by name or keyword.page:inventory
doc:Documentation topics.doc:receivables
product:Products by name or code.product:rice
person:People by name or registration/record number.person:maria
sale:Sales by code or customer name.sale:1042
  • Prefixes are case-insensitive and tolerate surrounding whitespace: PRODUCT: rice works like product:rice.
  • A recognized prefix with no term yet shows a prompt explaining what can be searched (for example, person: asks for a name or document).
  • Unknown prefixes are treated as ordinary search text, not as errors.
  • Each resource type returns up to five results, and sensitive fields — like people's email and phone — are never included.

Keyboard use

  • ↑/↓ move through results, Enter opens the highlighted result, and Esc closes the palette.
  • Tab and the arrow keys move between category tabs when a tab is focused.

The endpoint behind the palette (GET /api/search/) is documented on the API Reference page.
