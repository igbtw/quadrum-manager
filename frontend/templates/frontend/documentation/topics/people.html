{% blocktrans trimmed %}People are the customer records used by sales and finance: students, teachers, staff, and visitors. The People page lists and filters them.{% endblocktrans %}

{% blocktrans trimmed %}Record types{% endblocktrans %}

  • {% blocktrans trimmed %}Student, Teacher, Staff, and Visitor — the record type is shown as a badge in the listing and in payment details.{% endblocktrans %}

{% blocktrans trimmed %}Record fields{% endblocktrans %}

{% blocktrans trimmed %}Field{% endblocktrans %}{% blocktrans trimmed %}Shown as{% endblocktrans %}{% blocktrans trimmed %}Notes{% endblocktrans %}
{% blocktrans trimmed %}Name{% endblocktrans %}{% blocktrans trimmed %}Name{% endblocktrans %}{% blocktrans trimmed %}Used for matching in listings and search.{% endblocktrans %}
{% blocktrans trimmed %}Type{% endblocktrans %}{% blocktrans trimmed %}Type badge{% endblocktrans %}{% blocktrans trimmed %}Student, Teacher, Staff, or Visitor.{% endblocktrans %}
{% blocktrans trimmed %}Record / Doc{% endblocktrans %}{% blocktrans trimmed %}Registration{% endblocktrans %}{% blocktrans trimmed %}A short identifier (for example, a student number) usable for lookup.{% endblocktrans %}
{% blocktrans trimmed %}Status{% endblocktrans %}{% blocktrans trimmed %}Active / Inactive badge{% endblocktrans %}{% blocktrans trimmed %}Inactive records stay in history but are excluded from the active listing.{% endblocktrans %}
{% blocktrans trimmed %}Balance{% endblocktrans %}{% blocktrans trimmed %}Balance column{% endblocktrans %}{% blocktrans trimmed %}Outstanding amount from open receivables. Negative values (red) mean the person owes money.{% endblocktrans %}

{% blocktrans trimmed %}Filtering and lookup{% endblocktrans %}

  • {% blocktrans trimmed %}The listing header has a search box that filters by name or registration; the URL parameter is preserved, so links can open a filtered listing directly.{% endblocktrans %}
  • {% blocktrans trimmed %}All types and All statuses selects narrow the visible rows by person type and active status.{% endblocktrans %}
  • {% blocktrans trimmed %}Each row has a copy action that puts the registration value on the clipboard.{% endblocktrans %}

{% blocktrans trimmed %}Searching for people from anywhere{% endblocktrans %}

  • {% blocktrans trimmed %}Press Ctrl+K and type a name or registration number — matching people appear under the People category.{% endblocktrans %}
  • {% blocktrans trimmed %}Use the person: prefix to search people only (for example, person:maria or person:123456), or switch to the People tab.{% endblocktrans %}
  • {% blocktrans trimmed %}Selecting a person opens the People listing already filtered to that name.{% endblocktrans %}
  • {% blocktrans trimmed %}Search results show only the name and record details — email and phone numbers are never returned by search.{% endblocktrans %}
