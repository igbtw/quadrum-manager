{% blocktrans trimmed %}Quadrum exposes JSON endpoints used by the point of sale and the global search. They live in frontend/views.py and are registered in frontend/urls.py. All of them require an authenticated session.{% endblocktrans %}

{% blocktrans trimmed %}Endpoint overview{% endblocktrans %}

{% blocktrans trimmed %}Method and path{% endblocktrans %}{% blocktrans trimmed %}Purpose{% endblocktrans %}
POST /api/pos/calculate/{% blocktrans trimmed %}Calculate a cart total from stored product data (read-only).{% endblocktrans %}
POST /api/pos/finalize/{% blocktrans trimmed %}Finalize a sale atomically, with idempotency.{% endblocktrans %}
GET /api/search/?q=term{% blocktrans trimmed %}Global search used by the command palette.{% endblocktrans %}
POST /api/pdv/calcular/, POST /api/pdv/finalizar/{% blocktrans trimmed %}Legacy aliases of the two POS endpoints, kept for compatibility.{% endblocktrans %}

{% blocktrans trimmed %}Authentication, methods, and CSRF{% endblocktrans %}

  • {% blocktrans trimmed %}Every endpoint is protected by sign-in; an anonymous request is redirected to /login/ (302), not answered with a 401/403.{% endblocktrans %}
  • {% blocktrans trimmed %}The POS endpoints are POST-only; an authenticated non-POST request returns 405. The search endpoint is GET-only.{% endblocktrans %}
  • {% blocktrans trimmed %}State-changing requests must carry a CSRF token, sent as the X-CSRFToken header or the csrfmiddlewaretoken form field.{% endblocktrans %}
  • {% blocktrans trimmed %}The POS endpoints read a JSON body (application/json) directly.{% endblocktrans %}

{% blocktrans trimmed %}Calculate total{% endblocktrans %}

  • {% blocktrans trimmed %}Request: {"items": [{"product_id": 12, "quantity": 2}]}.{% endblocktrans %}
  • {% blocktrans trimmed %}product_id and quantity must be positive JSON integers — booleans, floats (including 2.0), strings, null, zero, and negatives are rejected with 400. A missing quantity is rejected.{% endblocktrans %}
  • {% blocktrans trimmed %}A valid id that matches no active product returns 404; client-supplied prices are ignored.{% endblocktrans %}
  • {% blocktrans trimmed %}Success: {"total": "10.00"} — the total is a string with two decimals. An empty items list returns {"total": "0"}.{% endblocktrans %}
  • {% blocktrans trimmed %}The endpoint is read-only: it does not reserve or guarantee stock.{% endblocktrans %}

{% blocktrans trimmed %}Finalize sale{% endblocktrans %}

  • {% blocktrans trimmed %}Request fields: items (non-empty), optional customer_id (must be an active person), optional payment_method (exactly one of CASH, DEBIT, CREDIT, PIX, ON_ACCOUNT), and a required idempotency_key (1–255 characters, letters, digits, _ and -).{% endblocktrans %}
  • {% blocktrans trimmed %}Success returns {"success": true, "code": "VEN-000042", "message": "Sale completed"}.{% endblocktrans %}
  • {% blocktrans trimmed %}Side effects on a new sale (all in one atomic transaction): one Sale, one SaleItem per line with the stored unit price, stock reductions with a stock movement per item, and — for On Account sales with a customer — one account receivable.{% endblocktrans %}
  • {% blocktrans trimmed %}Insufficient stock is a business conflict (409 {"error": "Insufficient stock"}), not a server error; every write rolls back, so stock never goes negative.{% endblocktrans %}

{% blocktrans trimmed %}Idempotency and retries{% endblocktrans %}

  • {% blocktrans trimmed %}The request fingerprint is a SHA-256 over the normalized items (sorted product_id/quantity pairs), customer_id, and payment_method; item order and any client price are excluded.{% endblocktrans %}
  • {% blocktrans trimmed %}Retrying with the same key and equivalent contents returns the original sale code with 200 and writes nothing new.{% endblocktrans %}
  • {% blocktrans trimmed %}Reusing a key with different contents returns 409; a key owned by another user returns 403.{% endblocktrans %}

{% blocktrans trimmed %}Search endpoint{% endblocktrans %}

  • {% blocktrans trimmed %}GET /api/search/?q=term searches pages, documentation topics, products, people, and sales, returning up to five results per group.{% endblocktrans %}
  • {% blocktrans trimmed %}The query is whitespace-normalized and capped at 100 characters; at least two characters are required.{% endblocktrans %}
  • {% blocktrans trimmed %}The advanced prefixes page:, doc:, product:, person:, and sale: restrict the search to one group; an empty prefixed term returns a prompt instead of results.{% endblocktrans %}
  • {% blocktrans trimmed %}People results are matched on name and record/doc and never include email or phone fields.{% endblocktrans %}

{% blocktrans trimmed %}Error summary (finalize){% endblocktrans %}

{% blocktrans trimmed %}Status{% endblocktrans %}{% blocktrans trimmed %}When{% endblocktrans %}

403{% blocktrans trimmed %}Idempotency key belongs to another user.{% endblocktrans %}
404{% blocktrans trimmed %}customer_id provided but no active person matches.{% endblocktrans %}
409{% blocktrans trimmed %}Key conflict (different contents), incomplete prior attempt, or insufficient stock.{% endblocktrans %}
500{% blocktrans trimmed %}Unexpected failure; the response carries no internal detail.{% endblocktrans %}
