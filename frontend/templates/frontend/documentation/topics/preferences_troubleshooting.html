{% blocktrans trimmed %}Open the Preferences dialog from the header or search inside it; clearing the search shows all settings again. There is no “save” button — changes apply immediately. A stored preference is not the cause of data disappearing; clearing browser storage resets the interface to defaults.{% endblocktrans %}

{% blocktrans trimmed %}Troubleshooting{% endblocktrans %}

  • {% blocktrans trimmed %}Signed out unexpectedly? Sessions expire after a period of inactivity. Sign in again; saved data is not affected.{% endblocktrans %}
  • {% blocktrans trimmed %}Stock adjustment rejected? Stock cannot go negative. Reduce the quantity to remove or restock first.{% endblocktrans %}
  • {% blocktrans trimmed %}Payment rejected? The amount exceeds the remaining balance, or the receivable is cancelled. Overpayment is blocked at the form and service layers.{% endblocktrans %}
  • {% blocktrans trimmed %}Can't cancel a sale? A sale whose receivable already has registered payments cannot be cancelled, and only Completed sales can be cancelled.{% endblocktrans %}
  • {% blocktrans trimmed %}Product missing from the sale picker? Inactive products are hidden from selection but remain in history.{% endblocktrans %}
  • {% blocktrans trimmed %}Person missing from the listing? The listing shows active records; a record that was deactivated stays in history but is not listed.{% endblocktrans %}
